Valor por Extenso

Números e valores em reais escritos por extenso, do jeito certo para cheques, recibos e contratos.

Valor e opções

Aceita 1.234,56, 1234.56 ou R$ 1.234,56. Use o sinal de menos para negativos.

Escrever como
Gênero

Vale para números e ordinais: “vinte e uma”, “duzentas”, “vigésima”.

Exemplos

Use no seu projeto

Biblioteca JavaScript sem dependências, para Node.js e navegador, com linha de comando.

npm install github:micdog22/valor-por-extenso

import { porExtenso, ordinal, porcentagem } from 'valor-por-extenso';

porExtenso('1.234,56');
// 'mil duzentos e trinta e quatro reais e cinquenta e seis centavos'
porExtenso(21, { modo: 'numero', genero: 'feminino' }); // 'vinte e uma'
ordinal(23);          // 'vigésimo terceiro'
porcentagem('12,5');  // 'doze vírgula cinco por cento'
Regras usadas
  • 100 é “cem”; de 101 a 199 usa-se “cento e …”.
  • 1.000 é “mil”, nunca “um mil”.
  • Entre as classes (mil, milhão…) o “e” só aparece quando a classe seguinte é menor que 100 ou uma centena redonda: “mil e duzentos”, “mil e noventa e nove”, mas “mil duzentos e cinquenta”.
  • Milhões, bilhões etc. exatos levam “de” antes da moeda: “um milhão de reais”, mas “um milhão e quinhentos mil reais”.
